# 听打练习

一个本地听打（听写打字）练习工具：导入文章，一次读一小段，你边听边打，逐字比对正误，自动记录正确率、速度和进度。

纯本地运行：一个 HTML 页面 + 一个 Python 预处理脚本，不联网也能用（合成语音时除外）。

## 功能

- **边听边打**：语音播放的同时就能打字；打完全对自动跳下一段，打错了按 Enter 手动提交看对照
- **短段切分**：自动把文章切成 6–15 字的小段（可调），长句按标点均分，不会念出"半截词"
- **逐字比对**：中文按字、英文按词做对齐；绿色=对、红底=错，标点不计分，全角半角/大小写互通
- **速度统计**：每段显示"字/分钟"和用时，总结页有均速和最弱的 5 段，方便重点重练
- **多文章**：顶部下拉框随时切换文章，每篇独立记录进度
- **断点续练**：进度存在浏览器本地，关掉页面下次接着练
- **真人音色**：用 edge-tts 合成接近真人的中文语音，可调音色和语速；没装也能用系统语音凑合

## 安装

只需要一台装了 Python 3.9+ 的电脑（Windows/Linux/macOS 都行）。

### 1. 获取文件

把整个 `tingda/` 文件夹放到任意位置，比如桌面。里面的文件：

```
tingda/
├── index.html      练习界面（双击就能打开）
├── prep.py         预处理：切段 + 合成语音
├── article.txt     示例文章（听打的基本原理）
├── docs/           也可以把文章放这里
│   └── rhythm.txt  示例文章（速记的节奏感）
├── library.js      文章数据（prep.py 生成）
├── library.json    prep.py 的状态文件（自动生成，不用管）
└── audio/          语音文件（prep.py 生成，按文章分目录）
```

### 2.（可选）安装真人语音引擎

```bash
pip install edge-tts
```

- 装了：每段生成 mp3，音色接近真人，推荐
- 不装：也能跑，界面会用操作系统自带的语音朗读（Windows 自带中文音色，但机器味重）

## 使用

### 快速开始

```bash
cd tingda
python prep.py          # 处理所有文章，生成语音（第一次约 1-2 分钟）
```

然后双击 `index.html`（建议用 Chrome 或 Edge），点"开始听打"：

1. 语音开始播放，**直接跟着打字**（不用等念完）
2. 打完全对 → 自动跳下一段，不用按任何键
3. 有错字/漏字 → 按 **Enter** 提交，下方红绿对照看错在哪，再继续
4. 念完还没打完 → 继续打，打完再提交
5. 全部段落打完 → 自动出总结页（正确率、均速、最弱 5 段）

### 快捷键

| 按键 | 作用 |
|---|---|
| `Enter` | 提交当前段（播放中被拦截，防止误触；打全对不用按，自动跳） |
| `Esc` | 重听当前段（已打的字保留） |
| 下拉框 | 顶部切换文章；语速在右侧 0.7×–1.3× 随时调 |

### 添加自己的文章

把 txt 文章（UTF-8 编码）放进 `tingda/` 目录或 `docs/` 目录，然后：

```bash
python prep.py
```

- 已处理过的文章自动跳过，只处理新文章
- 想让界面显示自定义标题，在 txt 第一行写 `# 你的标题`
- 文章名（文件名）就是它的 id，以后改标题不影响已有语音和进度

其他常用命令：

```bash
python prep.py 我的文章.txt                  # 只处理这一篇
python prep.py 我的文章.txt --voice zh-CN-YunxiNeural   # 换音色（男声）
python prep.py --rate -20%                  # 全局放慢 20%
python prep.py --max 20                     # 每段最长 20 个字
python prep.py --no-audio                   # 只切段，不合成语音
python prep.py --force                      # 全部重新生成
python prep.py --list                       # 查看文章库
```

### 换文章、切文章

打开 `index.html`，顶部下拉框列出所有文章（`《标题》N 段`），点选即切。每篇文章的进度、成绩、语速都分开保存，互不影响；下次打开自动回到上次练的那篇。

## 判定规则

- **完全一致**（标点、空格、全角半角、大小写都不计）→ 自动提交进入下一段
- **有错漏** → 不会自动跳，按 Enter 手动提交；语音播放期间手动提交被拦截，等念完才能交
- **速度** = 实际打出的字数 ÷ 本段首次开播到提交的秒数 × 60。包含听和想的时间，中途重听不重置计时；粘贴文本（<1 秒）或中途离开（>1 小时）不计入速度

## 常见问题

**点开始没声音？**
先确认跑过 `python prep.py` 且对应文章目录下有 mp3。若某段合成失败，该段会自动改用系统语音。

**双击 index.html 提示"还没生成文章数据"？**
说明还没运行 `python prep.py`，或者运行失败。运行一次即可；也可以在页面里直接粘贴文章临时练习。

**进度丢了 / 想清零？**
进度存在浏览器的 localStorage，按文章 id 区分。清掉某篇进度：总结页点"重新开始"，或在浏览器开发者工具里删除 `tingda:文章id` 这个 key。注意不要用"无痕窗口"练习，关掉就没了。

**换了音色/语速想重听？**
`python prep.py --force` 会全部重新合成（约每百段 2 分钟）。

**想改每段长度？**
`--max 20` 放宽，`--min 5` 更碎。改完需要重新合成该文章（自动处理）。
